# CourseGenie MCP connector · releases

This repository is a public release channel for the CourseGenie WorkBuddy
MCP connector. The application source is maintained separately.

## Install

```powershell
uvx --from https://github.com/wen-sou-chen/coursegenie-mcp/releases/download/v1.0.0/coursegenie_mcp-1.0.0-py3-none-any.whl coursegenie-mcp
```

Requires Python 3.10+, `uv`, and a running CourseGenie backend.
